# FF14 G15 自動挖寶（SND）

SND（Something Need Doing）Lua 腳本：戰士單刷 G15 藏寶圖（古舊的蛇牛革地圖）與寶物庫 The Shifting Gymnasion Agonon。


## 需求

- SND（Lua 引擎）、vnavmesh、Wrath Combo、BossMod Reborn（只開閃避）
- 建議：Globetrotter（`/tmap` 時自動在精確藏寶點插旗）

## 使用前必填

在 SND 介面的設定中填入：`MapItemId`、`ChestName`、`PortalName`、`SphereName`。
